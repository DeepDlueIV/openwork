Specialized integrations connect your client's model picker to the OpenWork AI Gateway while also loading organization tools and skills through the MCP gateway.

An [MCP connection](/integrations/mcp) alone provides tools and skills. A specialized integration also loads the AI Gateway models your organization grants you, so you do not have to configure the two separately.

## OpenCode — ready

The published [`opencode-openwork`](https://www.npmjs.com/package/opencode-openwork) plugin is available for OpenCode 2. No OpenWork desktop app is required.

```sh
opencode plugin add opencode-openwork
opencode auth login openwork
```

Choose **Browser**, sign in, select your organization, and approve the matching code. OpenCode loads your granted AI Gateway models and OpenWork MCP resources on startup.

[Follow the complete OpenCode plugin guide](/model-context-protocol/opencode-plugin) for requirements, model and MCP checks, self-hosted options, and signing out.

Use [MCP integration](/integrations/mcp) with any compatible client. The client continues to use its own configured model provider unless a specialized integration connects the AI Gateway too.
