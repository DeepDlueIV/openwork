Add the OpenWork MCP gateway to a compatible client to use your organization's skills, plugins, workflows, and connected tools.

```text
https://api.openworklabs.com/mcp/agent
```

The gateway uses Streamable HTTP and browser OAuth sign-in. Sign in to OpenWork and choose your organization; the agent receives the resources assigned to you.

## How it works across clients

1. An admin shares skills and service connections with people or teams in OpenWork.
2. Each person adds the same gateway URL to their preferred MCP client and signs in.
3. The agent uses `search_capabilities` to find an authorized capability and `execute_capability` to use it. It can also use `list_skills` and `get_skill` to retrieve skill instructions.
4. OpenWork applies the member's access grants and connection tool settings to requests through the gateway.

Your team manages the shared resources once rather than copying MCP settings and skills into every client separately.

## Models and specialized plugins

Connecting MCP adds tools and skills; it does not replace the client's model provider. Use a [specialized client plugin](/integrations/client-plugins) to bring your organization's AI Gateway models into supported clients as well.

The [OpenCode plugin](/model-context-protocol/opencode-plugin) is ready. Specialized Cursor and Codex integrations are in progress; their MCP connections are available today.
